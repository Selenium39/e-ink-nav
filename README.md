# e-ink-nav

**nav.e-ink.me** — a lightweight ebook resources navigation site: free ebook libraries, book stores, library borrowing, reading apps, ebook tools, audiobooks and communities. Part of the [e-ink.me](https://e-ink.me) family (tools · [news](https://news.e-ink.me) · [wiki](https://wiki.e-ink.me) · [games](https://games.e-ink.me)).

- Static site, data-file driven (no CMS, no backend), deployed on Cloudflare Pages
- Legal resources only; no on-site submissions — suggestions by email: openminimax@gmail.com
- Design: paper & ink (monochrome, serif headings, library-catalog cards, e-ink-browser friendly)

See [PLAN.md](PLAN.md) for the full spec: categories, seed list, data schema, SEO and funnel design.
