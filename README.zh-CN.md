# nav.e-ink.me — 合法电子书资源目录

[English](README.md) · [中文](README.zh-CN.md)

**线上站点：[nav.e-ink.me/zh](https://nav.e-ink.me/zh)（中文） · [nav.e-ink.me](https://nav.e-ink.me)（English）**

一个人工挑选、中英双语的合法电子书资源目录：免费书库、正版商店、图书馆借阅、阅读应用、工具、有声书、社区和词典，并特别关注哪些资源在墨水屏上真的好用。每个条目都写清它提供什么、有哪些格式、什么价格、要不要注册。

每一处收录都有明确的合法理由：作品进入公有领域、权利人主动公开、公共机构出借，或正版商店销售。盗版和影子书库一律不收，以后也不收。

下面八个书栏与站点一一对应。表格是简版；站点上另有每栏的长文介绍、条目详情页，以及按格式、语言、价格的筛选。

免费电子书不等于来路不明的文件。这一栏里的每一处，免费都有明确的理由：作品已进入公有领域，权利人主动公开，或者学术出版社把某一版做成了开放获取。

## [电子书商城](https://nav.e-ink.me/zh/ebook-stores)

版权还在的书走这一栏。买到的通常是这家商店生态里的许可，不是可以随便转发的文件——真正要决定的是你已经在谁的生态里，以及你手里的设备到底吃哪种格式。

| 站点 | 提供什么 | 费用 |
| --- | --- | --- |
| [Amazon Kindle Store](https://www.amazon.com/kindle-store) | 最大的英文电子书商店；Kindle 格式（KFX、AZW3），绑定 Kindle 硬件与应用 | 付费 |
| [Kobo Store](https://www.kobo.com) | 卖 EPUB 和 Kobo 的 KEPUB——Kobo 阅读器的原生商店，另有可选的 Kobo Plus 订阅 | 付费 |
| [Google Play 图书](https://play.google.com/store/books) | 挂在 Google 账号上的书店，另有一千本自备文件的云书架 | 付费 |
| [Apple Books](https://books.apple.com) | 内置于每台 iPhone、iPad 和 Mac；EPUB 带 FairPlay DRM | 付费 |
| [微信读书](https://weread.qq.com) | 微信账号上的深度中文书库：限时免费读，无限卡会员在上层 | 免费 + 付费 |
| [豆瓣阅读](https://read.douban.com) | 按本计价的中文电子书和杂志，原创写作一条线很强 | 付费 |
| [京东读书](https://ebooks.jd.com) | 京东的电子书架：免费书、付费书和会员混在一起 | 免费 + 付费 |

书目、价格，甚至你能打开哪一国的店面，都跟着账号所在地走——美国 Kindle 店有的书，不保证德国店或日本店也有。中文商店默认读者在中国大陆。

## [图书馆借阅](https://nav.e-ink.me/zh/library-borrowing)

版权还在、你又不想买断时的正路：公共机构已经付过许可。你需要的是读者证，不是旁门。

| 站点 | 提供什么 | 费用 |
| --- | --- | --- |
| [Libby](https://libbyapp.com) | 用公共图书馆读者证借电子书和有声书（美国、加拿大、英国、澳大利亚、新西兰） | 凭借书证免费 |
| [Hoopla](https://www.hoopladigital.com) | 不排队的图书馆借阅：按月限量，而不是等副本（美国、加拿大） | 凭借书证免费 |
| [中国国家图书馆](https://www.nlc.cn) | 古籍数字化、现代电子书和读者门户借阅 | 凭读者证免费 |

预约、借期、同时能借几本，都由图书馆规定。热门新书的队可能比直接买还长——服务的意义本来就在这里。

## [电子书工具](https://nav.e-ink.me/zh/ebook-tools)

不好看、却决定一份合法文件到底好不好读的那一栏。其中两件和本站同属一个家族，只给短短的条目。

| 站点 | 提供什么 | 费用 |
| --- | --- | --- |
| [e-ink.me](https://e-ink.me) | 网页转 EPUB，以及 MOBI、PDF、EPUB、HTML、TXT 互转*（本家族）* | 少量免费额度，之后付费 |
| [iloveepub.com](https://iloveepub.com) | 浏览器里的 EPUB 工具集：压缩、合并、拆分、转换，文件不出本机*（本家族）* | 免费 |
| [Sigil](https://sigil-ebook.com) | 直接编辑 EPUB 的开源编辑器，改书而不是换包装 | 免费 |
| [Pandoc](https://pandoc.org) | 命令行转换器：Markdown、DOCX、HTML 转 EPUB 和 PDF | 免费 |

工具不会把文件洗白：转换一本你无权阅读的书，不会凭空产生阅读的权利。

## [有声书](https://nav.e-ink.me/zh/audiobooks)

有声书是一次表演，表演本身有自己的版权，哪怕底下那本书已经很老。所以古腾堡上的免费文本不会自动变成免费录音。

| 站点 | 提供什么 | 费用 |
| --- | --- | --- |
| [LibriVox](https://librivox.org) | 志愿者录制的公有领域有声书，可留存，多为 MP3 和 M4B | 免费 |
| [Audible](https://www.audible.com) | 亚马逊按积分订阅的有声书服务和商店——最深的英文商业书架 | 订阅 |
| [喜马拉雅](https://www.ximalaya.com) | 大型中文音频服务：有声书、讲座、播客 | 免费 + 付费 |
| [Storytel](https://www.storytel.com) | 以串流为主的订阅，北欧最强 | 订阅 |

图书馆也借商业有声书（见上面的 Libby 和 Hoopla）——只听一遍的书，那往往是更划算的价格。
